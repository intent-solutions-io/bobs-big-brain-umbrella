current Codex MCP `brain_search` tool. Responses identify `local-qmd`; each task query
used `scope: curated`, `limit: 3`, and returned three citations. Three earlier broad

sample, not representative adoption telemetry or an authenticated teammate round trip.

The [evidence record](039-AA-AUDR-project-use-and-context-contract-2026-10-27.evidence.json)
publishes allowlisted observations and private receipt hashes. Full returned citations,
export snapshots and historical row links are retained privately. These are unsigned
operator observations, not independent attestations; private receipts are not publicly
downloadable. No memory bodies, private citation identifiers, actor identities,
credentials, service addresses or raw client configuration are published.

The dated private inventory contains **133 repository records: 74 observed at its
2026-08-01 collection and 59 intentionally excluded reference trees**. All three
sampled repositories are present. This is a historical source denominator, not a
current estate census. Excluding fork/archive reference trees does not classify every
product's retirement or current activity. Other repositories and other teammates are
outside the sample. Missing usage telemetry remains unknown, not zero use.

## Proposed project-context contract

Use this brief in the existing session, PR or Bead notes. Beads remains the task/status
authority; source documents remain the design/operating authority. Do not create a
second Markdown task ledger or duplicate sensitive source content into a new vault.

| Field | Minimum evidence |
| --- | --- |
| Objective | Existing Bead, bounded outcome and acceptance; identify a mirror when native state is not inspected. |
| Sources and context | Owning repository, exact source references/revisions and relevant returned citations. Read enough cited content to support the intended claim. |
| Inputs and process | Scope, client/mode, authorized inputs, source-versus-target distinctions and the checks governing the work. |
| Outputs | Changed artifact/PR and actual verification results; distinguish source, release and deployment. |
| Feedback and reuse | State which knowledge helped, what was misleading or insufficient, and one reusable lesson proposed through the existing approved capture/review path. |
| Freshness | Observation date, source revision and measured timing; mark first-indexed visibility and use as unmeasured when they are. |
| Escalation | Stop dependent action when source conflicts, citation content, authority or access is insufficient; record the existing owning Bead and the missing evidence. |

The first action is a **manual three-session pilot** of this brief, using existing
Beads/PRs and supported search. Success means 3/3 sessions name the goal and source,
3/3 record verification and feedback, and zero unresolved stale/source conflicts are
silently used for an action. Record capture/promotion/index evidence where authorized,
or the explicit reason it remains unmeasured. Do not count audit calls as adoption.
`obk.2` owns this proposal; ambient automation remains with `39z.10` and its accuracy gate.
